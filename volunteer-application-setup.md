# Volunteer application deployment

1. Create the tables by running `volunteer-applications.sql`, `contact-submissions.sql`, and `booking-requests.sql` against the MySQL database used by the site. The local XAMPP database is named `teznet_technologies`. If `volunteer_applications` already exists with the previous numeric consent column, run `volunteer-applications-consent-migration.sql` once before deploying the updated application handler.
2. Configure the PHP environment variables `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, and `DB_PASS` with a database account permitted to insert form-submission rows.
   On this XAMPP installation, the handlers also load `C:\xampp\private\teznet-db.php`; keep that file outside `htdocs` and restrict access to the Apache account and authorized administrators. Environment variables take precedence when already set.
3. Set `TEZNET_APPLICATION_UPLOAD_DIR` to a writable directory outside the public website document root. On this XAMPP installation, the local private settings file sets it to `C:\xampp\private\teznet-applications`, with access restricted to the Apache account, SYSTEM, and local administrators. The PHP process sets this directory to mode `0700` and uploaded files to `0600`. Grant filesystem access only to the web process and staff who are authorized to review applications. Do not expose the directory through a web server alias.
4. Use PHP 8.0 or later with PDO MySQL, Fileinfo, and ZipArchive enabled. Configure PHP with `file_uploads=On`, `upload_max_filesize=3M`, `post_max_size=14M`, and `max_file_uploads` of at least `4`. Confirm the web server request body limit is at least 14 MiB.
5. Serve the form and submit handler over HTTPS. Back up the private document directory and database using the same staff access controls.

Applications remain unavailable with an HTTP 503 response until the database and private storage settings are present. Uploaded filenames are replaced with random names; the original filename is kept only as application metadata.

6. Configure outgoing submission receipts in `C:\xampp\private\teznet-mail.php`. The settings must return `SMTP_HOST` (`smtp.gmail.com`), `SMTP_PORT` (`465`), `SMTP_USERNAME`, `SMTP_PASSWORD` (a Google App Password), `MAIL_FROM_ADDRESS`, and `MAIL_COMPANY_ADDRESS` (`fastnetworkug@gmail.com`). Keep this file private and never place the App Password in the website or source control. Enable Google 2-Step Verification and create an App Password for the sending account. A PDF copy is queued for the applicant and the company after each successful contact, booking, or application submission. Email delivery runs in a detached PHP worker, so form confirmation is not delayed while Gmail processes the message. If queueing or email delivery fails, the submission remains saved and the confirmation page provides a download link; delivery failures are logged in the Apache error log.

7. Before deploying the booking estimator, run `booking-estimates-migration.sql` against the site database. It adds estimate and detected-quantity columns to `booking_requests` and creates or updates the consent-based `declined_booking_estimates` table. The estimator recognizes clear quantities in descriptions (for example, “2 flyers” or “three apps”), recalculates the total server-side, and saves the quantity with consented bookings or declined-estimate follow-ups. Quantities above 100 require a custom quote. Small / basic, Standard, and Large / complex estimates are calculated from each service's configured price range and scope factors, then multiplied by the detected quantity. Service rates and scope factors are configurable in `booking-pricing.php`; estimates use those configured ranges without additional pricing discounts. They are estimates, not binding offers; Teznet should review and update them before hosting. Public Uganda pricing references include [Marv Web Design's website cost guide](https://marvwebdesign.com/blog/how-much-does-a-website-cost-in-uganda), [Persmon Technologies' website packages](https://persmontechnologies.com/pricing/), and [Next Studio Photography's event packages](https://www.nextstudiophotography.com/packages). These sources provide only partial benchmarks; ranges for services without public local rate cards are estimates and should be confirmed by Teznet. Equipment, materials, printing, travel, hosting, licenses, and third-party fees may be quoted separately. Final pricing is confirmed after consultation. When a client consents to follow-up after declining an estimate, the details and recalculated estimate are saved in `declined_booking_estimates`; a confirmation email is queued to the client only.
